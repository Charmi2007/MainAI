# MaintAI

Explainable, Risk-Aware Predictive Maintenance Using Machine Learning.

## Features
- Machine failure probability estimates
- Random Forest and Decision Tree comparison
- Adjustable risk alert threshold
- Sensor-based maintenance guidance
- Evaluation metrics and interactive charts

## Run locally
1. Use Python 3.11 or 3.12.
2. Open a terminal in this project folder.
3. Install dependencies: pip install -r requirements.txt
4. Run: streamlit run app/app.py

## Important
This academic prototype uses the UCI AI4I 2020 dataset.
Predictions are not guarantees of machine safety.
